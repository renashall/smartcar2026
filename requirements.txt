# Python packages for the "Machine Learning with Raspberry Pi & Smart Car" course.
#
# Easiest install (laptop/desktop): from the repo root, run the helper in Code/.
# It makes a .venv in the repo root and installs everything below into it:
#     python Code\setup.py        # Windows
#     python3 Code/setup.py       # macOS / Linux
#
# Or install straight into your current environment with:
#     pip install -r requirements.txt
#
# You only need these on whichever machine runs the lesson programs (camera
# viewer, face detection, GUI). On the Pi, Code/setupPart1.sh and
# Code/setupPart2.sh already install them for you; install here yourself only on
# a separate computer (or if Pi setup was skipped).
#
# No terminal? In Thonny use Tools -> Manage Packages and install each name below.

numpy            # arrays / image math (Lessons 6c, 7, 8, 11, client)
opencv-python    # cv2: video decode, face detection, drawing (Lessons 7, 8, 11)
Pillow           # PIL: image helpers used by the client
PyQt5            # the GUI window for the client and Lesson 11

# --- Raspberry Pi only: car hardware libraries ---
# These control GPIO, the camera, the LED strip, and the I2C/ADC board. They
# only install on a Raspberry Pi, so they are left commented out here. On the Pi
# they are installed by Code/setupPart1.sh / Code/setupPart2.sh (apt, plus the
# WS281x LED driver), not by this file. Uncomment them only if you are setting up
# a Pi by hand without the setup scripts.
#
# RPi.GPIO       # GPIO pins (motors, buzzer, ultrasonic, line sensors)
# rpi_ws281x     # the addressable LED strip
# picamera       # the Pi camera (Lesson 6 server side)
# smbus2         # I2C bus for the ADC / battery / photoresistors
